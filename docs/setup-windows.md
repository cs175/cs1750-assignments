**Setup Instructions for Windows**

**William Zhang**

- Install Visual Studio 2022 (Community edition) here:
  https://visualstudio.microsoft.com/downloads/
- In the Visual Studio Installer, make sure to include Desltop development with C++.
  Installing other components is optional but unnecessary.

- You may need to restart your computer to complete the installation.
- In the assignment starter code, open the file asst1.vcxproj with Visual Studio
  by double clicking on that file's icon. (Do not start VS any other way!)
- To check that everything works, press the green arrow.
  This buttons builds and executes your code. The mode you choose to build the project in doesn't
  matter too much, but I prefer to do all development in "Debug" mode (which is better for error
  logging) and then do my final build in "Release" (which executes much faster).
  You can also see the executable at ./Debug/asst1.exe and run it by cd'ing into the root directory
  of this project and executing ./Debug/asst1 in a terminal.
- If this window pops up, you're in good shape to start the assignment!
